# Wii Remote Xbox

Ремаппер Wii Remote + Nunchuk в виртуальный контроллер Xbox 360 для Windows.
Использует Bluetooth HID, hidapi, vgamepad и драйвер ViGEmBus.

## Установка и запуск

1. Установите Python 3 для Windows с Python Launcher (`py`).
2. Установите драйвер [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases). Без него виртуальный Xbox-контроллер не создастся.
3. Скачайте репозиторий и распакуйте его в отдельную папку.
4. Запустите `setup.cmd`: он создаст `.venv` и установит зависимости. Установка vgamepad также может предложить установку драйвера.
5. Подключите Wii Remote по Bluetooth средствами Windows и присоедините Nunchuk.
6. Запустите `run_wii_xbox_bridge.cmd`.

Для остановки нажмите Ctrl+C в окне программы. `stop_wii_xbox_bridge.cmd` принудительно завершает экземпляры из этой папки.

## Раскладка

| Wii Remote / Nunchuk | Xbox 360 |
| --- | --- |
| Стик Nunchuk | Левый стик |
| Крестовина Wii Remote | Правый стик |
| Движение стика Nunchuk | Удержание L3 |
| Нажатие крестовины | Удержание R3 |
| Wii Remote B / A | RT / RB |
| Wii Remote + / − | Y / X |
| Wii Remote 1 / 2 | Start / Back |
| Nunchuk C / Z | LB / LT |

Вертикальные оси обоих стиков инвертированы. Триггеры переключаются между 0 и 255. Остальные кнопки не назначены.

## Ограничения

- Поиск устройства настроен на Nintendo RVL-CNT-01, VID `057E`, PID `0306`. Другие модели и клоны могут потребовать доработки.
- Используется первый найденный Wii Remote; поддерживается один виртуальный контроллер.
- Скрипт не выполняет сопряжение Bluetooth и не изменяет его настройки.
- В репозиторий включён исходный алгоритм ремаппинга. Работа переносимой сборки на физическом контроллере отдельно не проверялась.
- Готовые сторонние DLL, драйверы и Python-модули не включены: зависимости устанавливаются через pip.

Исходное описание раскладки сохранено в `original_mapping.txt`; фраза о работе в фоне отражает состояние исходного компьютера на момент его создания.
